# Исходные данные

CSV из материалов учебного проекта (данные Росстата), разделитель `;`, кодировка UTF-8.

- `hotel.csv` — средства размещения, 2018–2023
- `count_person_hotel.csv` — размещённые в гостиницах, 2023
- `tour_firm.csv` — реализованные турпакеты, 2018–2023
- `tour_cost_2023.csv` — стоимость турпакетов, 2023
